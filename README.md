# داشبورد تحلیلی جمعیت ایران

### مسابقه تحلیل داده ایران – گروه تحلیلگری

## معرفی پروژه

این پروژه یک **داشبورد تعاملی تحلیل شاخص‌های جمعیتی، اجتماعی و اقتصادی ایران** است که با هدف ایجاد تصویری یکپارچه، قابل فهم و داده‌محور از روندهای جمعیتی کشور طراحی شده است.

داشبورد با استفاده از داده‌های رسمی **مرکز آمار ایران** تهیه شده و امکان بررسی روند شاخص‌ها در بازه زمانی مختلف و در سطوح مختلف جغرافیایی از جمله کشور، مناطق شهری و روستایی را فراهم می‌کند.

تمرکز اصلی پروژه بر تبدیل داده‌های خام آماری به **اطلاعات قابل تحلیل و قابل استفاده برای تصمیم‌گیری** است.

---

## اهداف داشبورد

* نمایش روند تغییرات جمعیتی در طول زمان
* بررسی ساختار و ترکیب جمعیت
* تحلیل تفاوت‌های جمعیتی میان مناطق شهری و روستایی
* بررسی روندهای تولد، مرگ، ازدواج و سایر شاخص‌های جمعیتی
* تحلیل شاخص‌های مرتبط با جمعیت فعال، اشتغال و بیکاری
* بررسی وضعیت دانش‌آموزان، فارغ‌التحصیلان و ساختار آموزشی
* مقایسه مقدار شاخص‌ها در ابتدای و انتهای دوره انتخاب‌شده
* نمایش تغییرات و نرخ رشد شاخص‌ها به صورت تعاملی
* فراهم کردن امکان فیلتر و تحلیل بر اساس سال و سطح جغرافیایی

تمام داده‌های آماری مورد استفاده در این پروژه از منابع رسمی **مرکز آمار ایران** تهیه شده‌اند.

## روش طراحی و توسعه

فرآیند تهیه داشبورد در دو مرحله اصلی انجام شده است.

### مرحله اول – طراحی در Power BI

در مرحله نخست، مدل داده، شاخص‌ها، Measures و ساختار بصری داشبورد در **Microsoft Power BI** طراحی و توسعه داده شد.

در این مرحله موارد زیر انجام شد:

* طراحی Data Model
* ایجاد Dimensionها
* آماده‌سازی داده‌ها
* تعریف Measures با زبان DAX
* طراحی صفحات تحلیلی
* انتخاب Visualهای مناسب
* ایجاد Slicerها و فیلترهای تعاملی
* بررسی نتایج و اعتبارسنجی شاخص‌ها

### مرحله دوم – تبدیل به Web Dashboard

با توجه به نیاز پروژه به ارائه یک نسخه مستقل و قابل اجرا در محیط وب، ساختار داشبورد Power BI به یک **Web-based Interactive Dashboard** تبدیل شد.

در این مرحله:

* ساختار داده‌ها به فرمت JSON تبدیل شد.
* منطق محاسباتی و شاخص‌ها به JavaScript منتقل شد.
* صفحات داشبورد با HTML و CSS پیاده‌سازی شدند.
* تعاملات و فیلترها با JavaScript توسعه داده شدند.
* نمودارها و کارت‌های تحلیلی در محیط وب بازسازی شدند.

در بخش توسعه و تبدیل نمونه اولیه Power BI به نسخه HTML/JavaScript، از **ChatGPT به عنوان ابزار کمکی در تحلیل، توسعه و رفع خطاهای کدنویسی** استفاده شده است.
